## Original contribution in this repository

The original system combines a fixed editorial paper theatre, narration-locked timing, deterministic Chinese typography, semantic action manifests, physical slot and mask validation, same-source layer decomposition, silent-readability review, full-film geometry checks, and owner/steward state separation.

Public examples must remain sanitized. Do not commit private narration, user images, generated episode media, credentials, personal absolute paths, or project QA traces.
